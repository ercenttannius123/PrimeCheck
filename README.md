# PrimeCheck

PrimeCheck is a small web project that I built to check whether a number is prime or not.

You just need to enter a number and click the Check button. The app will tell you whether the number is prime. It also handles invalid inputs, such as empty values and decimal numbers.

## Features

- Check if a number is prime or not.
- Show a message if no number is entered.
- Only accept whole numbers.
- Handle zero, negative numbers, and numbers below 2.
- Use square root to make the checking process more efficient.

## Built With

- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `PrimeCheck` folder.
3. Open `index.html` in your browser.
4. Enter a number and click the Check button.

That's it! No extra setup or installation is needed.
